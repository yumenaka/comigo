# 当前 REST 修改回归检查（本地记录，不提交）

结论：发现并修复 3 个问题；已测试的常用流程正常。旧 REST 路由移除会影响外部客户端与新旧版本混用的远程书库，未添加兼容层。

## 发现与修复

1. **P1：非法端口导致服务中断**。隔离实例 PATCH `/api/configs` 传入 `Port:70000` 返回 200，随后日志明确显示 `listen tcp: address 70000: invalid port`。原 JSON 更新缺少范围校验，本轮新增自动重启让错误立即中断服务。`config.UpdateConfigByJson` 现在在提交副本前校验 0–65535，保留既有端口 0 语义；增加负数和越界值回归用例。
2. **P1：重启中接受配置却遗漏应用**。测试将重启占用标志置为 true，原处理器仍返回 200、修改端口并跳过重启。`routers/control.go` 现在在写入前取得占用标志，冲突返回 409，配置保持不变。新增 `TestConfigUpdateWhileRestarting`，修复前失败、修复后通过。
3. **P2：通用列表设置增删失败**。真实 Chromium 在“排除路径”新增中文项，旧前端向新接口发送 `addValue`，返回 400。列表组件现在 POST/DELETE 都发送原文 `value`；删除无用 base64 编码函数。新增项出现、删除项消失均已由浏览器验证，两个请求都返回 200。同一组件用于排除路径、图片扩展名和书籍扩展名。
